It simply discards the exits code which I found out the hard way; when
my own code (from a running fedora install) while creating `/swap/swapfile`.

You can reproduce it simply without ever needed to even have a `btrfs` FS.
Or to be running a scripted installation.

```console
$ btrfs filesystem mkswapfile --size 64M nocow; echo "$?"
ERROR: cannot set NOCOW flag: Operation not supported
exit=0
$ ls -l nocow
-rw------- 1 user user 0 Oct 19 23:13 nocow
```
Link: [#1186](https://github.com/kdave/btrfs-progs/issues/1186)
